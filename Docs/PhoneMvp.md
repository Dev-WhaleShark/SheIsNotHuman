# 휴대폰 MVP

기존 `OrderDocument` 원본을 Bottom 책상 위 휴대폰으로 사용한다. 물품 전달 후 휴대폰을 클릭하면 신분증과 함께 원본이 카메라 쪽으로 이동한다. 휴대폰 홈에서 **윗치폼**을 누르면 현재 NPC의 주문번호·고객 이름·고객 코드·상품·수량을 확인할 수 있고, **X**를 누르면 오프라인 샘플 피드가 열린다. 휴대폰의 `HOME` 또는 `<` 버튼은 홈으로 돌아간다. 판정은 기존 확대 화면의 PASS/NON PASS 버튼에서 한다. 앱을 닫거나 NPC가 바뀌면 휴대폰은 홈으로 초기화된다.

현재 환경에서 Unity Editor 입력과 새 스크립트 import가 작동하지 않아 씬과 프리팹은 아직 생성·저장되지 않았다. Editor 사용이 가능해지면 다음 **한 번의 메뉴 실행**으로 적용한다.

1. Unity 6000.5.4f1에서 `Assets/Scenes/PerspectiveCubeViewPrototype.unity`를 열고 저장되지 않은 변경이 없는 Edit Mode인지 확인한다. Prefab Mode에서는 대상 씬으로 돌아온다.
2. `Tools > Inspection MVP > Install phone MVP`를 실행한다. 메뉴가 보이지 않으면 먼저 기존 작업을 저장하고 Unity의 `Assets > Refresh` 또는 Editor 재시작으로 새 스크립트를 가져온다. 이 메뉴가 새 한글 TMP 아틀라스 생성, 기존 `OrderDocument.prefab` 갱신, 대상 씬 저장을 순서대로 처리한다. 다른 문서 프리팹은 편집하지 않는다.
3. Console의 `[PhoneMvp] Installed ... phoneRefs=7/7` 로그와 저장된 씬·프리팹을 확인한다. 오류가 나면 변경된 에셋과 씬 dirty 상태를 확인한 뒤 원인을 수정한다. 실패를 성공으로 간주하거나 저장되지 않은 씬을 버리지 않는다.

검증할 동작: 휴대폰 최초 클릭으로 확대, 윗치폼 주문 정보와 현재 NPC 데이터 일치, X 화면 전환과 홈/뒤로, 닫고 다시 열기, 다음 NPC와 다시 시작 때 데이터 초기화, PASS/NON PASS 진행, Front 화면에서 앱 버튼 입력 차단, 1920×1080 및 1280×720에서 텍스트·버튼 가독성. 이 항목의 실제 Play Mode 결과는 **미실행**이다. 앱 내용은 네트워크에 연결되지 않으며 메신저·뉴스·선입금 기능은 이번 범위에 포함하지 않았다.
